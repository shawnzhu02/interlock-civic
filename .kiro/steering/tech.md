# Tech

- **Python 3.9 or later.** CI runs 3.9, 3.12 and 3.13 on Linux and 3.13 on Windows (`.github/workflows/test.yml`). Do not use syntax newer than 3.9: no `match`, and no `X | Y` type unions at runtime.
- **The standard library only, at runtime.** `pyproject.toml` declares `dependencies = []`, and it stays that way. HTTP calls use `urllib`. Storage uses `sqlite3` or the JSONL journal.
- **Dev-only dependencies are allowed** under `[project.optional-dependencies]`:
  - `hypothesis`, for property-based tests.
  - `temporalio`, which already exists for the Temporal demo.
  - Tests that need them skip cleanly when the dependency is missing. Follow the pattern of `HAS_TEMPORAL` in `tests/test_explained.py`.
- **Tests use `unittest`.** Run them with `python -m unittest discover -s tests`. New test files are `tests/test_<feature>.py`.
- **Stripe: test keys only.** The Stripe client refuses anything that is not a test key (`interlock/targets/stripe_api.py`). Keys come from the environment (`STRIPE_SECRET_KEY`), and never from code, logs, or the browser.
- **Generated results.** `results/*.md` and `viewer/traces.js` are generated by `python experiments/run_all.py` and `python viewer/build.py`. Never edit them by hand. CI fails if they drift from the code.
- **Time is injected.** Code that depends on time takes a `clock=` or `now=` argument, so that tests are deterministic.
- **Web UI.** The UI is static HTML, CSS and JavaScript served by the standard-library server in `backend/api.py`. There is no build step. Any library is pinned to an exact version from a CDN.
